# BOTANÉ – Project Specification

**Project:** BOTANÉ  
**Tagline:** The Art of Simple Skincare  
**Project Type:** Skincare Product Catalogue  
**Development Approach:** Spec-Driven Development

## 1. Project Overview

BOTANÉ is a fictional premium skincare brand with a digital product catalogue. The platform allows customers to explore skincare products, browse categories and discover product ingredients and descriptions.

The application will feature a luxury minimalist visual identity with a clean layout, neutral colors and elegant typography.

## 2. Problem Statement

Customers often struggle to find organized information about skincare products, their ingredients and product categories.

BOTANÉ aims to provide a centralized and user-friendly catalogue where customers can easily discover and explore skincare products.

## 3. Project Objectives

- Develop a modern skincare catalogue.
- Organize products into categories.
- Display detailed product information.
- Provide product search and filtering.
- Create an administration system for managing products.
- Develop a responsive interface.

## 4. Functional Requirements

- Users can view the homepage.
- Users can browse products.
- Users can view product details.
- Users can browse products by category.
- Users can search for products.
- Administrators can create, update and delete products.

## 5. Technology Stack

**Frontend**

**Backend**
- ASP.NET Core Web API

**Database**

**Development Tools**

## 6. Database Entities

- Product
- Category
- Ingredient
- ProductIngredient

## 7. System Architecture

The application follows a client-server architecture.

The React frontend communicates with the ASP.NET Core backend through REST API endpoints using HTTP requests.

The backend handles application logic and communicates with the SQLite database through Entity Framework Core.

## 8. Design Requirements

- Luxury minimalist appearance.
- Ivory, beige and soft sage colors.
- Elegant typography.
- Clean product cards.
- Responsive layout.
- Simple navigation.

## 9. Development Methodology

The project follows Spec-Driven Development. Requirements and architecture are defined before implementation begins.

## 10. Expected Result

A functional skincare product catalogue supported by a React frontend, ASP.NET Core backend and SQLite database.
